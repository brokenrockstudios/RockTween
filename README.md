# Rock Tween

A small lightweight tweening library for gameplay and UI. 
A continued 2nd iteration of several years of a previously unreleased plugin tween library called RockPolishLibrary.

## Install

1. Add to `<YourProject>/Plugins/`.
2. Build your project.

A C++ toolchain is required; this download does not contain precompiled binaries.
